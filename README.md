# Ascend Protocol

An anime-inspired "System" fitness app: personalized workouts, nutrition targets, XP and ranks, and 3-week progress check-ins.

Monorepo layout (in progress):

- `packages/core` — shared logic: nutrition math, workout plan generator, XP/ranks, trial/billing timeline, original lore
- `server` — Node.js API + PostgreSQL
- `app` — Expo (React Native) mobile app
- `docs` — research sources, legal/IP notes, Play Store setup
